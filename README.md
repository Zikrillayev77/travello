## ✨ Bo'limlar

- 🧭 **Navbar** — navigatsiya menyusi
- 🌅 **Hero** — asosiy sarlavha va harakatga chaqiruvchi tugmalar
- 🛎️ **Services** — taklif qilinadigan xizmatlar
- 🗺️ **Destinations** — mashhur yo'nalishlar

## 📁 Tuzilma

```
src/
├── Components/
│   ├── Navbar.jsx
│   ├── Hero.jsx
│   ├── Services.jsx
│   └── Destinations.jsx
├── App.jsx
└── main.jsx
```

## 🚀 Ishga tushirish

```bash
git clone https://github.com/Zikrillayev77/travello.git
cd travello
npm install
npm run dev
```

Brauzerda `http://localhost:5173` manzilini oching.

Production uchun build:

```bash
npm run build
npm run preview
```
